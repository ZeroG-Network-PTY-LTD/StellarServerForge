## 🚀 HOW TO USE

### Quick Start with Presets

```
1. Open Config (Ctrl+C)
2. Click a preset:
   - Low-End (budget)
   - Medium (balanced)
   - High-End (performance)
3. Customize if needed
4. Save
```

### Save Configuration

```
1. Configure all settings
2. Click "💾 Save As..."
3. Choose location
4. Name the file
5. Save
```

### Load Configuration

```
1. Click "📂 Load..."
2. Select JSON file
3. Settings loaded
4. Click "Save Configuration"
```

### Validate Settings

```
1. Fill in configuration
2. Click "✓ Validate"
3. Review results
4. Fix any issues
5. Validate again
```
