## 🚀 Quick Start

### Run the Application:

```bash
# Option 1: Use the convenient script
run.bat

# Option 2: Run the JAR directly
java -jar target\stellar-server-forge-1.0.0.jar

# Option 3: Use Maven
mvn exec:java "-Dexec.mainClass=com.zerog.network.stellarforge.Main"
```

###Complete Workflow:

1. **Launch** → `run.bat`
2. **Configure** → Click "⚙️ Configure Server", edit settings, save
3. **Install Mods** → Click "📦 Install Mods", search, install
4. **Setup** → Click "🚀 Launch Server", click "⚙️ Setup Server"
5. **Add Files** → Place server.jar + mod loader (manual step)
6. **Launch** → Click "▶ Start Server"
7. **Monitor** → Watch live console, send commands
8. **Stop** → Click "⬛ Stop Server"

**Total Time:** ~5 minutes! 🎊
