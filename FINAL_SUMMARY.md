## 🎮 How To Use

### Quick Start (3 Commands):

```powershell
# 1. Build (optional - already built!)
build.bat

# 2. Run
run.bat

# 3. Or run JAR directly
java -jar target\stellar-server-forge-1.0.0.jar
```

### First-Time Setup:

1. **Configure API Key** (Optional for mod installation)
   - Open `config/api-keys.properties`
   - Add your CurseForge API key
   - Get key from: https://console.curseforge.com/

2. **Launch Application**
   - Run `run.bat`
   - Main window appears

3. **You're Ready!**
   - Install mods
   - Setup servers
   - Launch servers
