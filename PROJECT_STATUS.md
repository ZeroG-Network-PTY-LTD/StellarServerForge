## 🚀 GETTING STARTED

### Prerequisites
- Java 11+ (JDK for servers, JRE for app)
- CurseForge API key (from https://console.curseforge.com/)

### Quick Start (5 Minutes)
1. Run `run.bat` or `java -jar stellar-server-forge-1.0.0.jar`
2. Configure API key in `config/api-keys.properties`
3. Restart application
4. Start creating servers!

### Create Your First Server (10 Minutes)
1. Configure (2 min) - Set name, version, loader, RAM
2. Setup (3 min) - Automatic server files
3. Install Loader (3 min) - Automatic Forge/Fabric/Quilt/NeoForge
4. Install Mods (2 min) - Optional, from CurseForge/Modrinth
5. Launch - Click and play!
